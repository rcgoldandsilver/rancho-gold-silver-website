IMPORTANT BEFORE ADMIN LOGIN WORKS
1. Put this website in a GitHub repository.
2. In admin/config.yml replace REPLACE_WITH_GITHUB_USERNAME/REPLACE_WITH_REPOSITORY.
3. Configure Decap CMS authentication for the final host.
4. Publish the site and use https://YOUR-DOMAIN/admin/.
